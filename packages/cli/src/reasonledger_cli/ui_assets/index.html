What do these states mean?
proposed
Extracted from your docs and waiting for you. It is not in the ledger yet and counts as evidence of nothing until you confirm it.
confirmed
You reviewed it and accepted it. This is the human-oversight step the ledger exists to record — who accepted the decision, and when.
active
A decision in force, recorded directly (by an agent or a person) rather than through doc import. It is listed under Decisions, never under Proposals.
pending review
Recorded, but no person has judged it yet, so nobody has vouched for it. Read it, then Approve it here or run reasonledger approve.
agreed
Whose idea the choice was: a person stated it or explicitly accepted it before the agent acted. Separate from review — an agreed decision can still be pending.
recommended
Whose idea the choice was: the agent chose or proposed it. A person may approve it later; it stays recommended, because that is where it came from.
superseded
Replaced by another decision — one written to replace it, or one a person chose to keep when two clashed. It is kept, never deleted: the trail has to show what was believed before and when it changed.
retired
Taken out of force by a person, with a reason. It is kept as history and shown here and in why, but it is no longer guidance and is left out of conflicts.
stale
Still in the ledger, but an assumption it depended on no longer holds — either marked stale, or a watcher condition has been breached. Worth re-deciding.
replaces dec_…
The doc behind an already-confirmed decision changed. Confirming this proposal retires the old decision; rejecting it leaves the old one untouched.
orphaned
The decision names a file that is no longer in the repo — usually a refactor or deletion. The decision may still be sound; its pointer is not. Re-target it or retire it.
conflicts
Pairs a model judged to answer the same question in ways that clash. Related decisions that are not judged yet are only similar topics — run reasonledger judge to check them.
whole file only
In “Why”, a decision anchored to a file rather than a function or line range. It describes the file, not necessarily the exact code you asked about.
